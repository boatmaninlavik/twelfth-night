# 十二夜

> If music be the food of love, play on.
> — 莎士比亚《第十二夜》

一个微信小程序。你讲一段关于某个人的事，留下一段自己的声音，
过一天，收到一首**用你自己的嗓子唱出来的**、只为这件事写的歌。

---

## 这个仓库

```
miniprogram/    小程序前端（原生 WXML/WXSS/JS，无框架）
server/         Node 服务：接单、编排、交付
  worker/       音频处理（Python + shell）
  modal/        云端算力入口
```

## 技术上大致是怎么做的

- **写词**：把用户讲的事和一首参考歌交给大语言模型，产出歌词，
  以及一段描述"这首歌该听起来是什么样"的编曲说明。
- **出歌**：交给音乐生成模型，再把成品分成人声和伴奏两轨。
- **换声**：用用户那段二十秒左右的录音做声纹参考，把人声轨换成他自己的嗓子，
  在云端 GPU 上完成。
- **精修**：一条八道工序的处理链 —— 遮罩、气息支撑、音色与空间对齐、
  呼吸处理、身份校验、母带。最后一道是响度闭环，
  把人声与伴奏的比例拉到一条固定的基线上，不随每首歌的编曲密度漂移。

前端所有装饰（花环、小丑、银冠）都是代码生成的矢量图，没有位图资源；
作品页那颗十二芒星同时是播放键和进度钟 —— 一首歌走满一圈。

## 跑起来

需要 `server/.env`（照 `server/.env.example` 填）和一个数据库
（`server/schema.sql` 建表）。之后：

```bash
cd server && npm install && npm run dev
```

小程序端用微信开发者工具导入 `miniprogram/`。
